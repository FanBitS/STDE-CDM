# Notebook

`wind_fica_aligned_trace.ipynb` provides an inspectable trace from generated
wind scenarios to the FICA interface. Its outputs are cleared in the public
release to avoid machine-specific state.

Start Jupyter from the repository root so every relative path resolves:

```bash
jupyter lab notebooks/wind_fica_aligned_trace.ipynb
```

The maintained reproducibility entry points are the Python files in `scripts/`;
use those for formal reruns.
